- Histórico com filtros

- Indicações
- Backup JSON
- Importação de backup
- Exportação CSV de oportunidades e clientes
- Funcionamento offline depois de instalado como PWA

COMO TESTAR
1. Extraia o ZIP.
2. Abra index.html no navegador.

COMO INSTALAR NO CELULAR
Para instalar como app e usar o modo offline corretamente, hospede a pasta em HTTPS.
Opções: Netlify, Vercel, GitHub Pages ou servidor próprio.
Depois abra o endereço no celular e escolha “Adicionar à Tela de Início”.

LIMITAÇÃO DESTA VERSÃO
Os dados são salvos no navegador/aparelho. Isso é adequado para 1 usuário por aparelho.
Para equipe multiusuário, sincronização em nuvem, login e painel central, conecte o front-end
a um backend (por exemplo Supabase/Firebase/PostgreSQL).

BACKUP
Use a aba Backup com frequência. O JSON exportado pode ser importado em outro aparelho.
